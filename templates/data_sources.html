Overview

This page explains the data sources we use to build the Registered Apprenticeship Finder and how that information appears throughout the site. Being clear about where our information comes from is an important part of making this tool transparent and trustworthy.

On this page

  2. New York State registered apprenticeship programs
  3. O*NET® occupational data
  4. AI-generated career descriptions

New York State apprenticeship opportunities

Apprenticeship opportunities that are currently recruiting comes from the New York State Department of Labor’s listings of Apprenticeship Announcements.

Each announcement contains details specific to each job, like the apprenticeship sponsor, number of openings, application dates, requirements, and how to apply.

New York State registered apprenticeship programs

Registered apprenticeship programs and sponsors comes from the New York State Department of Labor’s List of Active Sponsors.

A registered apprenticeship program includes its sponsor(s), regions, the official trade name, and the program length.

O*NET® occupational data

This site incorporates information from O*NET Web Services by the U.S. Department of Labor, Employment and Training Administration (USDOL/ETA). O*NET® is a trademark of USDOL/ETA.

We add O*NET® occupational data to opportunity and program data to better match users to possible careers. Specifically, we look at the skills, work activities, and work styles associated with an occupation when matching users.

For a specific example, you can see O*NET® occupation details for Electricians.
